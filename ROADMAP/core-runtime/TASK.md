# F01 — Runtime и управляющее хранилище

**Зависимости:** нет.

- [x] F01-T01 — Разделить CLI на `jasta web` и `jasta admin`
  1. Сохранить текущий Goppy entrypoint и разнести запуск по явным ролям.
  2. Настроить независимые listeners и конфигурацию для каждой роли.
  **Приёмка:** команды запускаются отдельно; web не открывает admin-маршруты, admin не обслуживает публичный контент.

- [x] F01-T02 — Добавить SQLite-схему управляющих данных
  1. Описать миграции для сайтов/доменов, настроек и снимков, релизов, источников архивов, владельца/сессий, заданий и сертификатов.
  2. Подключить Goppy SQLite ORM только к `jasta admin`.
  **Приёмка:** чистая база мигрирует; повторное применение миграций безопасно; web не открывает файл SQLite.

- [x] F01-T03 — Передавать активные снимки web через Unix-сокет
  1. Зафиксировать формат снимка активных доменов, конфигураций и путей релизов.
  2. Добавить admin-команду отправки снимка и web reload без перезапуска.
  **Приёмка:** корректный снимок заменяет in-memory состояние web; ошибочный снимок отклоняется, предыдущая активная версия продолжает обслуживаться.

- [x] F01-T04 — Импортировать поддерживаемые YAML-конфиги сайтов
  1. Добавить локальную CLI-команду импорта в SQLite.
  2. Поддерживаемые SPA/MPA конфиги преобразовывать; устаревшие или неполные файлы перечислять в отчёте.
  **Приёмка:** импорт не изменяет исходные YAML и контент; повторный запуск не создаёт дубликаты; неподдерживаемые файлы не теряются и явно отмечены.
