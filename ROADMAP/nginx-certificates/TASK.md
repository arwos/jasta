# F05 — Nginx и сертификаты

**Зависимости:** F01-T01, F01-T03, F04-T03.

- [x] F05-T01 — Генерировать и безопасно применять Nginx-конфигурацию
  1. Генерировать отдельные server blocks для сайтов и admin-домена в принадлежащей Jasta include-зоне.
  2. Поддержать проксирование в localhost listeners и путь HTTP-01 challenge.
  3. Перед reload выполнять `nginx -t`; ограничить операцию одним include-файлом и фиксированными командами проверки/reload. Unix-права для systemd admin на include, challenge root и reload задаёт F07-T01.
  **Приёмка:** неверная конфигурация не активируется и не прерывает текущие worker-процессы; валидная применяет изменения штатным reload. Admin не принимает путь или команду из API request.

- [ ] F05-T02 — Выпускать локальные self-signed сертификаты
  1. Создавать ключ и сертификат с SAN для указанного локального домена.
  2. Сохранять сертификат отдельно от релиза с правами для admin/Nginx.
  **Приёмка:** сертификат проходит локальную криптографическую проверку, покрывает выбранный домен и не выдаётся как публично доверенный.

- [ ] F05-T03 — Получать и продлевать Let’s Encrypt сертификаты через HTTP-01
  1. Сохранять ACME account key и временно публиковать challenge-ответ через Nginx на порту 80.
  2. Выпускать и продлевать сертификаты обычных доменов; передавать прогресс в admin jobs.
  **Приёмка:** успешный выпуск сохраняет сертификат и приводит к проверенному Nginx reload; challenge failure сохраняет работающий текущий сертификат; wildcard отклоняется с понятной ошибкой.
