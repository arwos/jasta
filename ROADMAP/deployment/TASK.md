# F03 — Импорт архивов, релизы и rollback

**Зависимости:** F01-T02, F01-T03, F02-T01; интеграция Markdown builder зависит от F02-T04.

- [x] F03-T01 — Безопасно принимать ZIP и TAR.GZ
  1. Потоково ограничивать вход 100 МБ и распакованный объём 1 ГБ; значения читать из конфигурации.
  2. Распаковывать только в staging, отклонять path traversal, escaping symlinks, malformed headers и чрезмерное число записей.
  **Приёмка:** архивы обоих форматов корректно извлекаются; превышение каждого лимита и злонамеренные пути отклоняются без записи вне staging.

- [x] F03-T02 — Скачивать архив из внешнего HTTPS-источника
  1. Поддержать URL с query-подписью и конфигурируемые HTTP Basic/Bearer credentials.
  2. Проверять DNS-ответы и IP назначения перед каждым соединением и после redirect; запрещать loopback/private/reserved адреса.
  **Приёмка:** public/private registry проходят с поддержанным типом auth; HTTP, локальный IP, DNS rebinding и redirect во внутреннюю сеть блокируются; секреты и signed URL редактируются в логах.

- [ ] F03-T03 — Создавать проверенный неизменяемый релиз
  1. Проверять тип приложения и отдельную конфигурацию сайта до активации.
  2. Собирать контент и сохранять рядом снимок конфигурации и метаданные источника.
  **Приёмка:** failed validation/build не создаёт активного релиза; успешный релиз имеет постоянный ID и не изменяется после сборки.

- [ ] F03-T04 — Атомарно активировать релиз
  1. Переключить контент и связанный config snapshot как одну активную версию.
  2. Передать обновлённый снимок в `jasta web` через reload-сокет.
  **Приёмка:** посетитель видит целиком старый или целиком новый релиз; web не перезапускается; ошибка reload сохраняет прежнюю активную пару.

- [ ] F03-T05 — Откатывать контент и снимок конфигурации
  1. Переключать сайт на выбранную сохранённую пару «релиз + config snapshot».
  2. Показывать историю, текущую версию и дисковое пространство релизов.
  **Приёмка:** rollback возвращает и контент, и конфиг; все версии остаются до ручного удаления; ошибки не удаляют текущий релиз.
