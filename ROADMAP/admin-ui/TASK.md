# F06 — React-админка

**Зависимости:** F04-T03, F04-T04, F04-T05; экраны используют F03 и F05.

- [ ] F06-T01 — Создать frontend build в `ui/admin/`
  1. Настроить React, TypeScript, Vite, Tailwind CSS с `@tailwindcss/vite`, Oxlint и pnpm.
  2. Добавить воспроизводимый lockfile и команды lint/build; включать build output в `jasta admin`.
  **Приёмка:** frontend собирается, lint проходит, admin бинарник раздаёт собранное приложение; версии toolchain задокументированы.

- [ ] F06-T02 — Реализовать вход владельца и настройку TOTP
  1. Добавить пароль+TOTP login, enrollment, подтверждение, показ recovery codes и logout.
  2. Обрабатывать истечение access JWT и обновление refresh-сессии.
  **Приёмка:** защищённые маршруты закрыты для анонимного пользователя; UI не сохраняет или повторно не показывает секреты enrollment/recovery.

- [ ] F06-T03 — Управлять сайтами, доменами и конфигурацией
  1. Показывать список сайтов и формы SPA/MPA/Markdown/Redirect конфигураций.
  2. Показывать состояние доменов и сертификатов.
  **Приёмка:** UI отображает серверные ошибки валидации и сохраняет конфиг только после успешного ответа API.

- [ ] F06-T04 — Публиковать архивы и управлять версиями
  1. Добавить загрузку архива и выбор URL-источника.
  2. Показывать job progress, историю релизов, активную версию и действие rollback.
  **Приёмка:** UI показывает конечный результат/ошибку job; список релизов соответствует backend, откат требует явного действия владельца.

- [ ] F06-T05 — Управлять registry-секретами и TLS-действиями
  1. Добавить создание/редактирование URL источника и HTTP Basic/Bearer secret.
  2. Добавить действия выпуска/продления сертификатов и состояние выполнения.
  **Приёмка:** сохранённые секреты не возвращаются UI в открытом виде; ошибки Nginx/ACME показываются без секретных данных.
