# F06 — React-админка

**Зависимости:** F04-T03, F04-T04, F04-T05; экраны используют F03 и F05.

- [x] F06-T01 — Создать frontend build в `ui/admin/`
  1. Настроить React, TypeScript, Vite, Tailwind CSS с `@tailwindcss/vite`, Oxlint и pnpm.
  2. Добавить воспроизводимый lockfile и команды lint/build; включать build output в `jasta admin` через Go embed.
  3. Раздавать UI и SPA routes только на настроенном admin host; зарезервированные API/WebSocket/upload paths не получают fallback index.
  **Приёмка:** frontend собирается, lint проходит, admin API отдаёт собранное приложение, версии toolchain и runtime requirement задокументированы.

- [x] F06-T02 — Реализовать вход владельца и настройку TOTP
  1. Добавить экран входа владельца по паролю и TOTP, logout и экран подтверждённой сессии. Согласованный enrollment остаётся в `jasta owner-bootstrap`; команда показывает recovery codes ровно один раз, UI не получает их.
  2. Держать access/refresh tokens только в памяти страницы. Обновлять короткий access JWT заранее и повторять защищённый RPC при `unauthorized`; при refresh failure очищать сессию. Reload страницы требует повторного входа.
  **Приёмка:** UI закрывает защищённые разделы до login; пароль/TOTP очищаются после попытки; токены и recovery codes не попадают в DOM, localStorage, sessionStorage или логи; logout отзывает refresh-сессию backend.

- [x] F06-T03 — Управлять сайтами, доменами и конфигурацией
  1. Создавать сайты и показывать список; редактировать конфигурации SPA/MPA/Markdown/Redirect через типовые формы.
  2. Валидировать и сохранять конфигурацию как черновой снимок; новая конфигурация вступает в силу вместе с публикацией, rollback восстанавливает конфиг релиза.
  3. Показывать состояние доменов и сертификатов.
  **Приёмка:** UI отображает серверные ошибки валидации и сохраняет конфиг только после успешного ответа API. Create/update методы проверяют owner session и конфликты доменов; черновик не активируется без релиза.

- [ ] F06-T04 — Публиковать архивы и управлять версиями
  1. Добавить загрузку архива и выбор URL-источника.
  2. Показывать job progress, историю релизов, активную версию и действие rollback.
  **Приёмка:** UI показывает конечный результат/ошибку job; список релизов соответствует backend, откат требует явного действия владельца.

- [ ] F06-T05 — Управлять registry-секретами и TLS-действиями
  1. Добавить создание/редактирование URL источника и HTTP Basic/Bearer secret.
  2. Добавить действия выпуска/продления сертификатов и состояние выполнения.
  **Приёмка:** сохранённые секреты не возвращаются UI в открытом виде; ошибки Nginx/ACME показываются без секретных данных.
