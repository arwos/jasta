# Контекст F02 — Обслуживание типов сайтов

## Согласованные решения

- SPA fallback использует главный `index.html`; MPA разрешает каталоги и их `index.html`.
- Markdown front matter — YAML; `slug` обязателен и уникален, задаёт root-relative URL, `/` разрешён для главной страницы. `title` и `description` необязательны.
- Markdown отображается через Go `html/template`; статические файлы копируются без изменений.
- RedirectPageApplication сохраняет path/query; статус 301 или 308 настраивается по правилу.
- Неизвестный домен получает явную ошибку и не сопоставляется случайному сайту.

## Состояние репозитория

- `internal/pkg/application/spa.go` и `mpa.go` уже обслуживают часть статических файлов, но не соответствуют целевому точному контракту полностью.
- `internal/pkg/application/mda.go` и `rpa.go` пока содержат panic-заглушки.
- Общие конфигурационные структуры живут в `internal/pkg/config`; действующий production YAML пример устарел.
- F02-T01 нормализует host и записи доменов одинаково: убирает завершающую точку и валидный порт, приводит ASCII DNS-имена к нижнему регистру и приводит IP-адреса к канонической записи. Unicode-домены задаются в ASCII A-label/punycode форме. Некорректный host получает HTTP 400, неизвестный нормализованный host — 523.
- Каждый service регистрируется в runtime только после проверки всех доменов; конфликт, включая совпадение после нормализации, отклоняет весь service или snapshot и не меняет активное состояние. Тот же путь регистрации применяется к YAML на старте и снимкам reload.

## Зависимости и проверенные источники

- Пользователь выбрал [go-markdown](https://github.com/osspkg/go-markdown); актуальная Go-документация: [pkg.go.dev/go.osspkg.com/markdown](https://pkg.go.dev/go.osspkg.com/markdown).
- Документация пакета указывает, что raw HTML по умолчанию экранируется; стандартные лимиты — 16 MiB input, глубина 128 и 1,000,000 tokens. Сборщик должен ограничивать входы на файл и весь релиз; `WithUnsafeRawHTML` не включать без отдельного решения.
- Go `html/template` выбран пользователем для шаблонов. Шаблоны сайта следует считать доверенной частью конфигурации; значения front matter — недоверенным вводом.

## Низкорисковые предположения

- Slug нормализуется как URL-путь; дубликаты проверяются после нормализации.
- Для Markdown страницы `title`/`description` доступны в template data, но не обязательны.
- Файлы со скрытыми/резервными именами и симлинки из архива обрабатывает общий безопасный архивный слой F03.
