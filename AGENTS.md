# Инструкции для работы с проектом

## Дорожная карта

- Перед изменением кода прочитай `ROADMAP/ARCHITECTURE.md`, задачу в `ROADMAP/<feature>/TASK.md`, а также соответствующие `CONTEXT.md` и `QA.md`.
- Реализуй ровно одну задачу, которую выбрал пользователь. Соблюдай зависимости между задачами; не начинай соседние задачи в рамках того же запроса.
- Ставь статус `[x]` только после выполнения критериев приёмки и необходимых проверок. `[~]` означает частично выполненную работу, `[!]` — конкретный блокер.
- Записывай решения, исправления пользователя и блокеры в контекст соответствующего feature. В `QA.md` фиксируй только реально запущенные команды и результаты; запланированные проверки помечай как запланированные.
- Сохраняй пользовательские изменения и не включай их в коммиты. Коммить только файлы текущей задачи с сообщением `<TASK-ID>: <короткое название>`.

## Команды, объявленные проектом

Команды ниже взяты из текущего `Makefile`; во время создания этой дорожной карты они не запускались:

- `make lint` — `goppy lint`.
- `make build` — `goppy build --arch=amd64`.
- `make tests` — `goppy test`.
- `make pre-commit` — lint, build и tests.
- `make ci` — `make install`, затем проверки `pre-commit`. `make install` устанавливает `goppy@latest` и выполняет `goppy setup-lib`; перед запуском проверь влияние обновления инструментов.

Frontend-команды будут зафиксированы после появления `ui/admin/package.json` в задаче F06-T01. До этого не считай pnpm-команды частью проверенного интерфейса проекта.
